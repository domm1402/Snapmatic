# Snapmatic

A mobile-first Snapmatic fan app with a GTA-inspired photo feed and private personal photo collection.

## Feed
- Includes a built-in set of GTA VI / Leonida-themed sample posts using publicly available game promotional screenshots.
- You can take photos or import pictures from your phone. Your own uploads appear in the same feed, marked with a subtle side stripe.
- Like and comment on built-in GTA posts. These interactions are saved locally on this phone.
- Like, comment on, edit, share, export and delete your own posts.
- Built-in sample posts are examples, not live posts from real players.

## Local storage and privacy
Your own photos, profile name, likes and comments are stored in this browser on this device. Nothing you upload is sent to a server or shown to other people. GTA sample images are loaded from external image hosts and need an internet connection. Clearing browser site data may erase your local content, so export important photos regularly.

## Install on Android
Open the GitHub Pages HTTPS site in Chrome, allow camera access, then choose Chrome's install option to add Snapmatic to your home screen. Camera access requires HTTPS or localhost.
