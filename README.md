# Snapmatic

An independent, mobile-first photo app inspired by the fictional in-game Snapmatic experience. It recreates the broad camera-first feel with an original interface and original visual assets. It is not affiliated with Rockstar Games.

## Features
- Camera-first interface with live viewfinder, HUD, grid, front/rear camera switching and shutter
- Self timer (3 or 10 seconds)
- Camera looks: Original, Golden, Noir, Vice, Retro and Chrome
- Import photos from the device
- Photo library with favourites and sorting
- Photo detail view with caption, date and location
- Editor with filters, brightness, contrast and saturation
- Share sheet / image export
- Camera ratio, quality, grid and location-stamp settings
- Profile and local photo archive
- PWA install support and offline app shell

## Run
Enable GitHub Pages for the repository (Settings → Pages → GitHub Actions). Open the deployed HTTPS URL on your phone and grant camera permission. Camera access requires HTTPS or localhost.

## Storage and privacy
Photos and profile settings are stored locally in the browser on the device. They are not uploaded to a server. Clearing browser site data can remove the local photo library, so export important images first.

## Important
This is an independent fan-made interpretation. It does not include Rockstar logos, extracted game assets, or proprietary artwork. The actual GTA VI in-game interface may differ from this concept.
