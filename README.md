# Snapmatic

A phone-first, installable Snapmatic-inspired photo app. This is an independent fan-made concept and is not affiliated with Rockstar Games.

## Features
- Mobile camera with front/rear camera switching
- Import photos from your device
- Photo roll stored locally in your browser
- Live camera looks: Normal, Sunset, B&W and Vivid
- Darkroom editor with looks, brightness and contrast
- Share or export individual photos and the full archive
- Installable PWA shell with basic offline caching
- Responsive dark interface with a Los Santos-inspired palette

## Run
Open `index.html` through a local web server or enable GitHub Pages for the repository. Camera access requires HTTPS (GitHub Pages works) or localhost. Photos stay in the browser's local storage and are not uploaded to a server.

## Notes
This project uses original CSS artwork and interface styling. It does not include Rockstar logos, game files, or proprietary assets.
